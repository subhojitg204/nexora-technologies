# NEXORA Technologies – Project Documentation

## 1. Project Overview

NEXORA Technologies is a responsive business website developed using React and modern frontend technologies.

## 2. Project Objectives

- Create a professional business website.
- Provide information about services and projects.
- Improve user experience through interactive features.
- Support desktop, tablet and mobile devices.

## 3. Website Pages

1. Home
2. About
3. Services
4. Portfolio
5. Pricing
6. Contact

## 4. Main Features

- Responsive navigation
- Dark and light theme
- Interactive portfolio
- Testimonials slider
- FAQ accordion
- Contact form validation
- Scroll progress indicator
- Back-to-top button

## 5. Technologies

- React
- JavaScript ES6+
- HTML5
- CSS3
- Vite
- React Router DOM

## 6. Testing

The website is tested using a production build and Google Chrome Lighthouse.

## 7. Conclusion

NEXORA Technologies demonstrates the development of a modern, responsive and interactive business website using React.
