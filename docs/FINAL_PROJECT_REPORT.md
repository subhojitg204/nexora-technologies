# CHAPTER 1: INTRODUCTION

NEXORA Technologies is a responsive, multi-page business website developed using React, JavaScript, HTML, and CSS. The purpose of this project is to create a modern online presence for a technology-based business and provide visitors with information about its services, portfolio, pricing, and contact details.

# CHAPTER 2: OBJECTIVES

- To develop a modern and responsive business website.
- To implement reusable React components.
- To create interactive website features.
- To provide a user-friendly navigation system.
- To implement dark and light themes.
- To improve accessibility and website performance.

# CHAPTER 3: TECHNOLOGIES USED

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- React Router
- Vite
- Git and GitHub
- Vercel

# CHAPTER 4: WEBSITE MODULES

1. Home Page
2. About Page
3. Services Page
4. Portfolio Page
5. Pricing Page
6. Contact Page

# CHAPTER 5: KEY FEATURES

- Responsive navigation and mobile menu.
- Dark and light theme toggle.
- Interactive portfolio filtering.
- Project details modal.
- FAQ accordion.
- Testimonials slider.
- Contact form validation.
- Scroll progress indicator.
- Back-to-top button.
- CSS animations and transitions.

# CHAPTER 6: TESTING

The website was tested for page navigation, responsiveness, interactive components, form validation, and production build functionality. GitHub Actions was configured to run an automated build check.
